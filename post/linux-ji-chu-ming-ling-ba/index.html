1、连接数
假设Tomcat接收http请求的端口是8083，则可以使用如下语句查看连接情况：
netstat –nat | grep 8083

2、线程
ps命令可以查看进程状态，如执行如下命令：
ps –e | grep java

通过如下命令，可以看到该进程内有多少个线程；其中，nlwp含义是number of light-weight process。
ps –o nlwp 27989

要想获得真正在running的线程数量，可以通过以下语句完成：
ps -eLo pid ,stat | grep 27989 | grep running | wc -l

Samba 实现文件共享及用户管理

  1. 添加 Linux 用户
    因为 Samba 用户必须是 Linux 中的用户，所以首先需要创建一个新的 Linux 用户。该用户将用于 Samba 登录。
    sudo useradd <用户名>
  2. 添加 Samba 用户及其密码
    在 Linux 用户添加完成后，我们需要将其添加为 Samba 用户。执行以下命令为该用户创建 Samba 账户和密码：
    sudo smbpasswd -a <用户名>
  3. 检查用户是否添加成功
    使用 pdbedit 命令可以查看当前 Samba 中的所有用户，确保步骤二中添加的用户成功添加：
    pdbedit -L
    . 删除 Samba 用户
    如果需要删除某个 Samba 用户，可以使用以下命令：
    sudo smbpasswd -x <用户名>

配置 Samba 共享文件夹
为了让 Samba 用户有一个独立的共享文件夹，我们需要手动创建一个目录并设置相应的权限。

  1. 创建共享文件夹
    进入你在 Samba 配置文件 /etc/samba/smb.conf 中指定的共享目录。例如，如果共享目录为 /srv/samba，你可以使用以下命令：
    cd /srv/samba

然后为每个用户创建一个专属的文件夹，建议文件夹名称与用户名一致：
mkdir <用户名>

  1. 设置文件夹权限
    设置文件夹权限非常重要，只有正确的权限设置才能保证文件夹的安全性和可访问性。以下是常用的权限配置：

700 权限：仅允许文件夹的所有者具有读写和执行权限，其他用户无权访问。
chmod 700 <文件夹名称>
3. 修改文件夹所属用户和用户组
Samba 共享目录的文件夹必须属于相应的用户。我们使用 chown 命令来更改文件夹的所有者和用户组：

chown <用户名>:<用户组> <文件夹名称>
四、配置 Samba 服务
在完成上述步骤后，你需要修改 Samba 的配置文件 /etc/samba/smb.conf 来添加新创建的共享目录。你可以添加如下的共享配置：

[alice]
path = /srv/samba/alice
valid users = alice
read only = no
browsable = yes
在上述配置中：

path 指定共享文件夹的路径。
valid users 定义可以访问此共享文件夹的用户。
read only 设置为 no，表示此共享文件夹对用户是可写的。
browsable 设置为 yes，表示此共享文件夹是可见的。
保存配置文件后，重启 Samba 服务以使更改生效：

sudo systemctl restart smbd
