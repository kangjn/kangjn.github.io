使用权限的符号表示法

虽然数字表示法简洁，但符号表示法可能更直观，特别是当你只想更改单个权限时。符号表示法使用字母来表示用户、组和其他用户，并使用运算符来添加或删除权限。
cd ~/project
echo '#!/bin/bash\necho "Hello, World"' > script.sh
这个命令做了两件事：

它创建了一个名为 script.sh 的新文件。.sh 扩展名通常用于 shell 脚本。shell 脚本是可执行文件，包含一系列按顺序执行的命令。
它将两行内容写入此文件：
    #!/bin/bash（称为 shebang）告诉系统这是一个 bash 脚本。shebang 行指定了应该用于执行脚本的解释器。在这种情况下，它是 /bin/bash，这是 Bash 解释器的路径。
    echo "Hello, World" 是一个命令，当脚本运行时将打印“Hello, World”。echo 命令只是显示跟随它的文本。
    \n 是一个换行符，确保命令在文件中位于单独的行上。

使用 whoami 命令来识别当前用户。
使用 uname 命令来显示内核名称。
使用 uname -a 命令显示所有系统信息。
使用 uptime 命令显示系统运行时间和负载平均值。
使用 id 命令来检索你的用户和组标识符。
使用 top 命令启动监控界面。
运行 top 后，按 q 键退出并返回到命令提示符。

使用 > 运算符重定向第一个命令的输出。这将创建文件（如果文件已存在，则会覆盖它）。
使用 >> 运算符将后续命令的输出 追加 到文件中，而不会删除其现有内容。

理解 tar 命令
tar 命令是一个强大的 Linux 工具，用于创建和操作归档文件。"Tar" 最初代表 "Tape Archive"（磁带归档），因为它最初设计用于将数据写入磁带，但如今它常用于在磁盘上创建压缩的归档文件。

当你使用 tar 时，你本质上是将多个文件捆绑成一个文件（称为归档），并且可以有选择地压缩此归档以节省空间。最常见的压缩格式是 gzip，它会给文件名添加 .gz 扩展名。

tar 命令使用不同的选项（标志）来控制其行为：

c: 创建一个新的归档
z: 使用 gzip 压缩归档
f: 指定归档的文件名

grep 命令非常适合在文本文件中搜索模式。
要将命令的输出保存到文件，你可以使用 > 重定向运算符。如果文件不存在，它将创建该文件；如果文件已存在，它将覆盖该文件。

dmesg 命令显示内核消息。你可以将它的输出 "管道"（pipe）到另一个命令进行过滤。
管道符 | 将一个命令的输出发送到另一个命令的输入。
grep 命令的 -i 选项可以使搜索不区分大小写。
要一次搜索多个模式（如 fail 或 error），你可以使用 grep -E 'pattern1|pattern2'。
注意：如果你遇到 "Operation not permitted" 错误，请尝试使用 sudo 运行命令以获得必要的权限。
