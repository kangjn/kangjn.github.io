Linux常见实践

2026-01-04 4 min read

服务器部署与管理
安装 Web 服务器：以 Apache 为例
在 Ubuntu 上安装 Apache：
sudo apt update
sudo apt install apache2

启动与停止 Apache 服务：
sudo systemctl start apache2 # 启动 Apache 服务
sudo systemctl stop apache2 # 停止 Apache 服务
sudo systemctl restart apache2 # 重启 Apache 服务

配置防火墙：以 UFW（Uncomplicated Firewall）为例
安装 UFW：
sudo apt install ufw

允许 Apache 服务通过防火墙：
sudo ufw allow 'Apache'

启用 UFW：
sudo ufw enable

开发环境搭建
安装 Python 开发环境
在 Ubuntu 上安装 Python 和 Pip：
sudo apt update
sudo apt install python3 python3-pip

创建虚拟环境（可选）：
python3 -m venv myenv
source myenv/bin/activate # 激活虚拟环境

安装 Java 开发环境
在 Ubuntu 上安装 OpenJDK：
sudo apt update
sudo apt install openjdk-11-jdk

设置 Java 环境变量：
sudo nano /etc/environment

在文件中添加以下内容

JAVA_HOME="/usr/lib/jvm/java-11-openjdk-amd64"
PATH="PATH:PATH:PATH:JAVA_HOME/bin"

保存并退出，然后使环境变量生效

source /etc/environment

系统监控与维护
查看系统资源使用情况：使用 top 命令
top # 实时查看系统的 CPU、内存、进程等资源使用情况

查看磁盘使用情况：使用 df 命令
df -h # 以人类可读的格式查看磁盘分区的使用情况

查看系统日志：使用 journalctl 命令
journalctl # 查看系统日志
journalctl -u apache2 # 查看 Apache 服务的日志

Linux最佳实践
安全配置
更新系统：定期更新系统软件包，修复安全漏洞
sudo apt update # 在 Ubuntu 上更新软件包列表
sudo apt upgrade # 升级已安装的软件包

使用 SSH 密钥认证：替代密码认证，提高 SSH 登录安全性
生成 SSH 密钥对：
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

将公钥添加到远程服务器：
ssh-copy-id user@server_ip

限制 root 用户登录：只允许普通用户登录，然后使用 sudo 获得临时管理员权限
sudo nano /etc/ssh/sshd_config

将 PermitRootLogin yes 改为 PermitRootLogin no

保存并退出，然后重启 SSH 服务

sudo systemctl restart sshd

性能优化
优化磁盘 I/O：使用 fstrim 命令清理未使用的磁盘空间
sudo fstrim -av # 清理所有支持的文件系统的未使用空间

调整内核参数：根据系统需求，调整内核参数以优化性能
sudo nano /etc/sysctl.conf

添加或修改参数，如 net.core.somaxconn = 65535

保存并退出，然后使参数生效

sudo sysctl -p

优化服务资源占用：关闭不必要的服务，减少系统资源消耗
sudo systemctl disable service_name # 禁止服务开机自启
sudo systemctl stop service_name # 停止正在运行的服务

自动化管理
使用脚本自动化任务：编写 shell 脚本，自动执行重复性任务
#!/bin/bash

这是一个简单的备份脚本

BACKUP_DIR="/backup"
DATE=(date +%Y%m%d%H%M%S) FILE_NAME="backup_DATE.tar.gz"
tar -czvf BACKUPDIR/BACKUP_DIR/BACKUPD​IR/FILE_NAME /data

保存脚本为 backup.sh，并赋予执行权限：
chmod +x backup.sh

可以使用 cron 任务调度器定期执行该脚本：
crontab -e
