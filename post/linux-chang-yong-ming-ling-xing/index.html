Linux常用命令行

2026-01-04 2 min read

ls：列出目录内容
ls # 列出当前目录下的文件和目录
ls -l # 以长格式列出详细信息
ls -a # 列出包括隐藏文件在内的所有文件

cd：切换目录
cd /home # 切换到 /home 目录
cd.. # 切换到上级目录
cd ~ # 切换到用户主目录

mkdir：创建目录
mkdir new_folder # 在当前目录下创建名为 new_folder 的目录
mkdir -p parent_folder/child_folder # 创建多级目录

rm：删除文件或目录
rm file.txt # 删除当前目录下的 file.txt 文件
rm -r folder # 删除名为 folder 的目录及其所有内容

文件与目录管理
复制文件和目录：使用 cp 命令
cp source_file target_file # 复制文件
cp -r source_folder target_folder # 复制目录

移动文件和目录：使用 mv 命令
mv old_file new_file # 重命名文件
mv file /new_directory # 将文件移动到新目录

查看文件内容：使用 cat、more、less 等命令
cat file.txt # 一次性显示文件全部内容
more file.txt # 分页显示文件内容，按空格键翻页
less file.txt # 功能与 more 类似，但支持向前翻页

用户与权限管理
添加用户：使用 useradd 命令
sudo useradd new_user # 添加新用户，sudo 表示以管理员权限执行

设置用户密码：使用 passwd 命令
sudo passwd new_user # 为新用户设置密码

查看用户权限：使用 id 命令
id new_user # 查看 new_user 的用户信息和权限

文件权限管理：使用 chmod 命令
chmod 755 file.txt # 设置文件的权限为所有者可读、可写、可执行，组用户和其他用户可读、可执行
